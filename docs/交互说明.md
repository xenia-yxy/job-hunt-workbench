# 交互说明 · 页面元素、状态与回显位置

> 落盘 2026-11-17。这份是"点哪里、看到什么、数据回到哪"的对照表，便于日常使用和后续改造定位。
> 深色 UI；工作台是壳 + iframe，页面在内容区切换，不单独开窗。

---

## 1. 工作台壳（工作台.html）

| 位置 | 元素 | 交互 | 说明 |
|---|---|---|---|
| 侧栏 | 导航行（首页/岗位判断与分析/投递/跟踪） | 点击切段 | 侧栏只放功能入口；产物不进侧栏 |
| 侧栏 | 数据概况块（在投族/样本/台账事件/视图） | 点击回首页 | 鼠标悬停有说明 |
| 顶栏 | 🧩 任务指令 | 开/关右侧抽屉 | Agent 任务的指令复制与执行记录都在这 |
| 顶栏 | ● 健康点 | 悬停看状态 | 绿=服务在线，红=异常；每 30 秒自动查 |
| 顶栏 | ↻ / ↗ | 重载当前页 / 新标签打开 | 调试用 |
| 面包屑 | 段名（可点回主视图） | 点击 | 当前视图名加粗；可写页有"可写"标记 |
| 视图条 | 本段产物 tab | 点击切换 | 变体/扫描出的报告在这切，不跳独立页 |
| 快捷键 | `/` 搜索、`[` 收放侧栏、`R` 重载、`Esc` 逐层关闭 | 键盘 | 输入框内不触发 |

**任务指令抽屉**（点 🧩 打开）：
- 接口配置（adapter/输出根/模板目录/渠道/说明）
- 「📋 复制通用任务指令」+ 每个模板的「复制此任务指令」
- 已落盘结果（按目录列文件名，只读）
- **执行记录时间线**（P3）：kind 下拉过滤 + ↻ 刷新；每条显示状态点/指令标题/类型/时间；点开看四段——① 指令原文 ② 回执 ③ 结果 ④ AI 写入。**刷新不丢**。

## 2. 岗位判断与分析（工作台-定位.html）①

| 区块 | 元素 | 交互 | 数据去向 |
|---|---|---|---|
| 我是谁 | 画像表单（学历/年限/技术栈/想法等） | 编辑 → 保存 | `POST /api/profile` → `config/local/profile.json`（写前留档） |
| 分析 | 「开始分析」 | 点击 | 建 `position-analysis` 脚本任务 → 秒级基线结果 |
| 分析结果 | 方向推荐表（行） | 点行就地展开 | 抽屉内显示能力全景/门槛/能力项/JD 原文；不跳独立页 |
| 分析结果 | 「交给 WorkBuddy 深析」 | 点击 | 建 `position-deep-analysis` agent 任务 → 任务面板复制指令 |
| 市场全景 | 表格 | 点行 | 同上就地展开 |
| 详情 | 「返回」 | 点击 | 回到分析结果/市场全景 |

**注意**：样本 ≤1 条的族会显式警告"参考度低"，别当成可靠结论。

## 3. 投递条件（工作台-投递条件.html）②

| 区块 | 元素 | 交互 | 数据去向 |
|---|---|---|---|
| 六份条件 | 条件卡片切换 | 点击选方向 | `GET /api/conditions` |
| L0 筛选 | 城市码/求职类型/学历/经验 | 改 → 保存 | `PUT /api/conditions` → 写条件文件（留档） |
| L1–L4 | 搜索词/否决/方向词/投放控制 | 改 → 保存 | 同上 |
| 投放控制 | 单轮投出上限 `f_max`、预算、日限 | 填/留空 | **留空=用条件文件值，不传默认值覆盖**（P-A） |
| 动作 | 「试跑 N 条（不投）」 | 填条数 → 点 | 建 `jkit-dry-run`，只判不投 |
| 动作 | 「真实投递」 | **连点两次（8 秒内）** | 建 `jkit-deliver`（confirm:true）→ 真投 |
| 动作 | 「重判已判过的岗位」勾选 | 勾选 | 试跑与真投都透传 recheck |
| 状态区 | 试跑结果参考 | 只读 | 不再阻断真投（软提示） |

## 4. 投递台账（工作台-投递台账.html）②的产物

- **只读**：不触发任何投递，不写主表。
- 筛选：按批次 / 结论 / 仅已投递 / 搜索（公司/岗位/job_id/依据）。
- 表格列：时间 / 批次:行号 / 公司 / 岗位 / 结论 / 依据判定 / 条件快照。
  - 「依据判定」**可展开**（P-D）：否决项、判定依据、评分、HR 状态、JD 摘录。
  - 「条件快照」显示本次实际条件摘要（P-B）：版本、生效筛选、搜索词、目标完成情况。
- 结论口径：只有 `delivered` 计入已投递。

## 5. 招聘跟踪（app.html）③

- **唯一可写主表**：编辑状态/备注 → 写 `data/ledger.json` + 重生成 CSV。
- 「📅 今日跟踪」：面试/待回复优先卡片；「🔄 抓取今日动态」建 `track-sync` 只读任务，回写后覆盖展示。
- 排序：多种口径（待办优先/有回复优先等）。
- 清理：手动 + 提醒，命中规则**打标不删**，二次确认才删。
- 🔧 宽松布局开关、待清理提醒横幅在开发中。

## 7. 常见状态与含义

| 状态 | 含义 | 该做什么 |
|---|---|---|
| 任务 `pending` | agent 任务已排队，等 WorkBuddy 取件 | 任务面板复制指令去会话执行 |
| 任务 `running` | 脚本任务执行中 | 等；别动那个浏览器标签页 |
| 任务 `done` | 完成 | 看结果/执行记录四段 |
| 任务 `failed` | 失败 | 看 error/日志；常见"没有已连接的浏览器"→ 拉 bsk daemon |
| 停止原因 `exhausted` | 候选耗尽、未投够 N | 放宽条件或加搜索词再跑 |
| 停止原因 `risk`/`guard`/`quota` | 风控/安全阀/配额熔断 | 等冷却，不要硬重试 |

## 8. 改动交互时的定位提示

- 改导航显示名 → `config/local/routes.json`（+ 模板轨 `config/routes.example.json`）。
- 改任务按钮行为 → `工作台-投递条件.html` 的 `startJob(...)` + `job_bus.js` 的 BUILTIN argv。
- 改执行记录时间线 → `工作台.html` 的 `loadInteractions()` + `job_bus.js` 的 `/api/interactions`。
- 改台账展示列 → `工作台-投递台账.html` 的 `render()` + `workbench_readonly.js` 的 `buildLedgerIndex()`。
- 改任何白名单文件后 → 跑 `python tools/sync_template.py` 同步 Public 模板轨 + `--check` 查脱敏。
